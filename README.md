PDF Password Recovery Using Johnny

Project Overview
This project demonstrates a practical PDF password security testing exercise using Johnny, the graphical user interface for John the Ripper.

The objective was to understand how password-protected PDF files can be tested for password strength in an authorized practice environment.

Objective
- Understand PDF password protection.
- Explore the Johnny graphical interface.
- Perform password recovery on a practice PDF.
- Understand the importance of strong passwords.
- Gain practical exposure to password security auditing.

Tools Used
- Operating System: Kali Linux
- Tool: Johnny (GUI for John the Ripper)
- Target: Self-created / authorized practice PDF
- Platform: VirtualBox

Practical Implementation

The project involved the following stages:

1. Set up the Kali Linux environment.
2. Opened the Johnny password auditing tool.
3. Selected the authorized practice PDF for testing.
4. Performed the password recovery exercise.
5. Observed the results displayed by the tool.

Results
The password recovery exercise was completed successfully on the authorized practice PDF.
This practical exercise helped demonstrate the importance of password complexity and secure document protection.


Key Learnings

- Basic understanding of Johnny and John the Ripper.
- Introduction to password security auditing.
- Understanding PDF password protection.
- Hands-on experience with Kali Linux.
- Importance of strong and complex passwords.

Disclaimer

This project was performed strictly for educational purposes using an authorized practice PDF.
Password auditing tools should only be used on files and systems for which explicit permission has been granted.

Conclusion

This exercise provided practical exposure to PDF password security testing and introduced the use of Johnny in a controlled cybersecurity learning environment.# PDF-Password-Recovery-Johnny
